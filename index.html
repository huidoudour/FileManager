FileManager

一个使用 Kotlin + Jetpack Compose 编写的轻量级 Android 文件管理器

文件管理 Jetpack Compose Material 3 开源

功能特性

📂 文件浏览

面包屑导航、路径记忆，支持按名称 / 大小 / 日期 / 类型多种排序方式

✂️ 文件操作

复制、剪切、粘贴（含冲突处理）、删除、重命名、新建文件 / 文件夹，支持多选批量操作

🔍 深度搜索

搜索当前目录及所有子目录，快速定位目标文件

🖼️ 媒体预览

基于 Coil 加载图片 / 视频缩略图，直观预览媒体内容

⭐ 收藏与快捷入口

收藏常用目录，侧边栏提供下载、相机、图片等快捷入口，一键跳转

👁️ 属性与控制

文件属性详情、文件夹大小计算、显示 / 隐藏隐藏文件

📤 分享与调用

分享文件到其他应用，支持被其他 App 调起选取文件（GET_CONTENT / OPEN_DOCUMENT / PICK）

📦 APK 安装

APK 文件通过 io.github.huidoudour.Installer 一键安装

💡 可配合 ApkSign App 使用，便捷浏览并选取 APK 文件进行签名安装

技术栈

Kotlin + Jetpack Compose Material 3 MVVM (ViewModel + StateFlow) Coil minSdk 24 targetSdk 37 compileSdk 37

构建

环境要求：JDK 11+、Android SDK 37

./gradlew :app:assembleDebug
